# Scene Segment Splitter - Python dependencies
#
# The app itself runs on the Python standard library only (tkinter included).
# The only optional package is the modern GUI theme:
sv-ttk>=2.6            # Sun Valley (Windows 11-style) ttk theme; GUI falls back gracefully if absent
#
# External BINARIES are required at runtime (not pip-installable):
#   ffmpeg, ffprobe, mkvmerge
# On Windows these are downloaded automatically into ./bin on first launch
# (see bootstrap.py). On macOS/Linux install them via your package manager, e.g.
#   brew install ffmpeg mkvtoolnix   /   sudo apt-get install ffmpeg mkvtoolnix
#
# Note: on Linux, tkinter is provided by the OS, e.g.  sudo apt-get install python3-tk
